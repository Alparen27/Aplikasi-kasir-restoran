# Aplikasi-kasir-restoran
Aplikasi Kasir Restoran merupakan program berbasis Python yang dirancang untuk membantu proses pengelolaan data menu, pelanggan, dan transaksi penjualan pada sebuah restoran. memiliki beberapa fitur, yaitu menambahkan data makanan dan minuman, menampilkan daftar menu, mencari menu, mengubah harga dan status ketersediaan menu, dan seterusnya
